요청 6: 카운터=6 -> 거절
요청 7: 카운터=7 -> 거절

[PASS] 카운터가 1부터 7까지 순서대로 증가

=== B. 슬라이딩 윈도우 (60초 3회) ===
t=100s: 제거=0, 기존 건수=0 -> 허용
t=130s: 제거=0, 기존 건수=1 -> 허용
t=155s: 제거=0, 기존 건수=2 -> 허용
t=156s: 제거=0, 기존 건수=3 -> 거절
t=170s: 제거=1, 기존 건수=2 -> 허용
t=171s: 제거=0, 기존 건수=3 -> 거절

[PASS] t=100,130,155 요청은 허용

[PASS] t=156 요청은 3건이 창 안에 있어 거절

[PASS] t=170에 req-1(t=100)이 창 밖으로 밀려 제거되고 허용

[PASS] t=171 요청은 다시 3건이 되어 거절

결과: 8/8 통과
